# Chata Berounka – Janov nad Nisou

Statická prezentace ubytování (HTML + CSS, bez build kroku).

Stránky: `index.html` (domů), `ubytovani.html`, `poloha.html`, `zima.html`, `leto.html`, `ceny.html`.
Fotografie jsou v `img/`, styly v `style.css`, písma (Bricolage Grotesque, DM Sans) se načítají z Google Fonts.

Lokální náhled: `python3 -m http.server` a otevřít http://localhost:8000
